#include <stdio.h>
#include <unistd.h>
int main() {
    pid_t pid = fork();
    if (pid == 0) {
        printf("This is the child process. PID: %d\n", getpid());
    } else if (pid > 0) {
        printf("This is the parent process. PID: %d\n", getpid());
    } else {
        printf("Fork failed!\n");   }
    return 0;}
Explaination: 
1- when pid==00, it runs the child block and print child pid using getpid() 
2- it runs the parent block and print parent pid using getpid()
3- if pid isn’t =0 or >0, it print else runs and prints fork failed

1-(4)
all: process_creation output_program simple_program

process_creation: process_creation.c
	gcc process_creation.c -o process_creation

output_program: file1.c file2.c
	gcc file1.c file2.c -o output_program

simple_program: simple_program.c
	gcc simple_program.c -o simple_program

clean:
	rm -f process_creation output_program simple_program
Explanation: The Makefile automates compiling all the C programs using gcc so I do not have to type each compile command manually every time.
all: This is the default target that runs when typing make. It depends on process_creation, output_program, and simple_program, so running make builds all three executables at once.
process_creation: Compiles process_creation.c into the executable file process_creation.
output_program: Compiles and links both file1.c and file2.c together into a single executable named output_program.
simple_program: Compiles simple_program.c into the executable file simple_program.
clean: Removes the three compiled executable files from the folder so the directory stays clean or can be rebuilt from scratch.
